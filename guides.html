A useful reading order

If you are choosing tires or wheels, start with the tire-size guide, then move to wheel offset and backspacing. If you are changing axle ratio or tire diameter, read the gearing guide before using the RPM & Speed Calculator. If you are comparing vehicles or modifications, read power-to-weight before treating a quarter-mile estimate as a promise.

How the library connects to the tools

The calculators are intentionally concise at the point of use. The guides carry the deeper explanation: definitions, worked examples, common mistakes and physical checks. Every major guide links back to a calculator so you can move from learning the measurement to testing your own numbers.

Editorial standard

GarageMath does not create near-duplicate pages for every possible tire size, wheel offset or vehicle. The goal is to publish a smaller set of useful reference pages that explain the underlying decision well enough to apply it to many builds. See the methodology page for formula, source and correction standards.
