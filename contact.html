CONTACT

Found a bad number? Send the inputs.

Corrections are most useful when GarageMath can reproduce the exact calculation you saw.

Calculator corrections

Email contact@garagemath.com with the calculator page, every input value, the result GarageMath displayed and the result you expected. If a manufacturer specification or reference supports the correction, include the source.

What to include in a report

  • Page address and complete inputs with units.
  • Observed output and expected output.
  • Source, calculation or steps supporting the concern.
  • Browser and device when reporting interface behavior.

Do not include VINs, passwords or other sensitive identifiers. Email contact is not an emergency service or a vehicle diagnostic appointment. No response-time guarantee is made.

Unclear assumptions

If the arithmetic is correct but the page does not make an assumption clear, report that too. GarageMath treats unclear limitations and ambiguous units as documentation defects.

Feature requests

Useful requests explain the real decision the new calculator would help with. A tool that solves a repeated automotive math problem is a better fit than a page created only to target a search phrase.

Business inquiries

Advertising, affiliate or other business inquiries can use the same address. GarageMath does not accept paid changes to calculator results or technical conclusions.
