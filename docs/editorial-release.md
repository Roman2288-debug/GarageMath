# GarageMath 3.6 editorial release

## Scope
All eleven calculator explanations expanded; fourteen decision guides written or substantially expanded. Existing canonical addresses retained. Six new guides indexed. OBD2 deferred pending data rights, provenance, applicability and editorial coverage.

## Source labels
Nominal: designation or simplified geometry. Published: exact product specification with conditions. Measured: physical observation with conditions/method. Estimated: model output. No universal fitment percentage or clearance margin.

## Review limits
Drafting and development use AI assistance. Automated math/UI fixtures, reference calculations and selected browser checks are not professional certification or a claim of independent human review. John owns the correction channel. No AdSense approval or new review submission is claimed.
